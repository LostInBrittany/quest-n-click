## 4.5.0, A4: the documentation access contract, the loader, the bundle and the two new tools

- **The loader** (`tools/wiki/docs-load.ts`). One in-memory set, from a package's `docs-bundle/` or the repository's `wiki/`: the index (`quest-n-click-docs-index` v1), the pages' Markdown, and a provenance that is identity only (`productVersion`, `productCommit`, `docRevision`, `buildId`, `source`, a label). The repository's set holds the `draft` and `ready` pages and says "repository preview"; a bundle holds `ready` pages only and says promotion is recorded outside it. An unknown major version of `index.json` or `bundle-manifest.json` is refused with a plain message. `read_doc {name}` reads `docs/en/<NAME>.md` in the repository (unchanged) and the bundle's `legacy/<NAME>.md` in a package; a package never reads `docs/en`.
- **The readings** (`tools/wiki/docs.ts`, no node import: the Studio page bundles it). Sections are cut at `<a name>` anchors outside fenced code. The search is deterministic: weights title and question 10, alias, keyword, identifier and a glossary term naming the page 6, section heading 4, body 2 (plus a little for repeats); a whole question, title or identifier typed counts once more; glossary words add the other language at 0.6. Below a score of 3, or with fewer than half the typed words found, a page is not a confident match. One result per page, its best section. `version` drops a page outside `appliesFrom`..`appliesUntil` (inclusive), or marks it `notApplicable` with `includeArchived`. Status is `current` until A5 brings deprecation. Cursors are `c1.` + base64url of the revision (the doc revision and a hash of every page file), the language, a hash of the request and the offset; a mismatch is `stale_cursor`.
- **`read_doc`'s compatibility.** Its schema keeps `name` and the same eight-value enum, adds `id`, `section`, `lang`, `cursor`, `maxChars`; `name` is no longer required, so `required` shrinks. A 4.4.0 client always sends `name` and is served byte for byte as before; one that sends nothing gets the explicit error "give either name (one of the 8 legacy pages) or id, not both" instead of a schema error. `name` with another argument is refused too. `tests/fixtures/mcp/read_doc-4.4.0.json` records the 4.4.0 server's schema (read from `tools/list` at c00b44fc, whose read_doc code is unchanged since), the eight calls and the 4.4.0 sizes; `tests/mcp-docs.test.ts` replays them through the real stdio server.
- **Where the tools are offered.** The stdio server over the core (repository and package) and the Assistant, local and demo (the demo snapshot embeds the wiki's index and ready pages beside the content guide, unchanged). Not the remote MCP: ADR 0029 makes each remote tool a request to the Studio's `/api`, which has no documentation route, and reading the client's own engine would answer for another version than the server's. A `GET /api/docs` route is left for later. The MCP instructions keep "read_doc CONTENT_GUIDE": steering agents to `search_docs` first waits for C2, when the index has pages.
- **The bundle** (`wiki -- bundle --out`, `tools/wiki/bundle.ts`): `index.json`, `md/<lang>/<id>.md` with links rewritten for a local reading, `legacy/<NAME>.md`, `assets/`, `bundle-manifest.json` (identity, the git tree of `wiki/`, each file's sha256 and size). No date. `scripts/pack.mjs` writes it into the prepared engine folder after the tracked files and before `npm pack`; the package has no `files` list, so it is packed as is. It is refused under any folder the repository tracks. Today: 9 files, about 306 kB, no page.
- **Checked.** `tests/wiki-access.test.ts` (loader, search, list, read by id, cursors, the tool's rules, reproducibility, hashes, legacy copies), `tests/mcp-docs.test.ts` (the eight calls, schema inclusion), `tests/docs-consumers.test.ts` (every reader of `docs/en|fr|img` or `wiki/` declared, A4 active or C2 switch), `external-consumer` (the archive's bundle against its manifest, and an MCP client over stdio against an installed project; run once locally on macOS, Node 22: green, `read_doc {name: "CONTENT_GUIDE"}` one block of 68,000 characters, the bundle's copy). The engine archive grows by the bundle (9 files). The MCP surface in `tests/api-surface.json` gains `search_docs` and `list_docs` and `read_doc`'s optional arguments; the quality baseline's surface hash follows.
