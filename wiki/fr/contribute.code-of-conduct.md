# Code de conduite

La règle que chacun suit dans les espaces du projet : issues, pull requests, discussions, relectures. Le fichier
[`CODE_OF_CONDUCT.md`](../../CODE_OF_CONDUCT.md) du dépôt en est le texte anglais ; cette page en est la référence dans
les deux langues.

<a name="expected"></a>

## Ce qui est attendu

quest'n'click est un petit projet, avec un seul mainteneur. Toute personne qui ouvre une issue, une pull request ou une
discussion doit rester respectueuse :

- pas de harcèlement ;
- pas d'insultes ;
- pas de discrimination ;
- pas de publication des informations privées de quelqu'un d'autre.

Le désaccord est bienvenu quand il porte sur le code, le contenu ou la décision, et qu'il reste poli.

<a name="reporting"></a>

## Signaler un manquement

Signalez-le en privé par les security advisories de GitHub sur `wanoo/quest-n-click`, ou au mainteneur, @wanoo. Les
signalements sont lus, reçoivent une réponse, et restent privés.

> [!LIMIT id=no-report-address]
> `CODE_OF_CONDUCT.md` envoie les signalements à « l'adresse du champ `author` de `package.json`, ou à celle du profil
> GitHub » ; `package.json` n'a pas de champ `author`, et le projet ne publie pas d'adresse électronique dédiée aux
> signalements. Tant que le mainteneur n'en donne pas une, utilisez les deux canaux privés ci-dessus.

<a name="consequences"></a>

## Ce qui suit un manquement

- Un premier manquement vaut un avertissement.
- Un manquement répété ou grave vaut une exclusion des espaces du projet.
- La conduite du mainteneur suit la même règle : dites-le-lui.

<a name="origin"></a>

## D'où vient ce texte

C'est une version courte et adaptée de l'idée du [Contributor Covenant](https://www.contributor-covenant.org/) 2.1,
écrite pour un projet de cette taille.
