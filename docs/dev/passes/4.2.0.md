# Passes, 4.2.0 "Stable World" (shipped before its people's passes, D38)

The candidate of 4.2.0 is 4.1.20's code with the version changed (plan 4.1.20 §12, D34): every criterion of 4.1.20's
sheet (`docs/dev/passes/4.1.20.md`) holds for it unchanged, and its own candidate re-proves the machine side. The
thirteen people's passes were meant for `v4.2.0-rc.2`; **none was made before the tag**, and 4.2.0 ships on a reduced
stable scope (D38, [GO / NO-GO 4.2](../GO-NO-GO-4.2.md)). They are made on `v4.2.0` itself
(`npm run field:init -- --release=4.2.0 --candidate=<the run the tag names>`, the command each issue gives once the
release exists); `npm run field:report` writes the table below, and a 4.2.x status release writes the verdicts.

The issues: `bridge-postgres-https` #77, `runs-real-players` #85, `run-resume-power-cycle` #84, `code-wheel-human` #78,
